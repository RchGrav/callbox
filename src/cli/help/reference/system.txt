callbox help system - root, sudo, and the global store

Root and sudo calls normally use the root-managed store:

  Linux: /var/lib/callbox
  macOS: /var/db/callbox

A launch whose executable or path argument resolves inside the invoking
user's home uses that user's store instead, including under sudo. Root
without a sudo user uses its own home for this check. This routing also
applies when --system is supplied.

Private root records and logs stay root-only. Normal users see only the
redacted public index, where a call's USER and COMMAND read 'hidden'.
Acting on a root-managed target requires root; user-local targets win
over root-public collisions.

  sudo callbox <cmd...>           start with root privileges
  sudo callbox list               list the global calls (authoritative)
  sudo callbox list -a            global calls plus every user's calls
  callbox list -s                 the redacted global view, as a normal user
  callbox purge -s                sweep the global store (re-execs via sudo)
