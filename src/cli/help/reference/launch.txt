backmux help launch - launch modes and options

  backmux call|agent|server|detach [options] PROGRAM [ARGS...]
  backmux shell [options] [SHELL [ARGS...]]
  backmux [options] [--] PROGRAM [ARGS...]      (also backmux run ...)
  backmux [options] TARGET

LAUNCH COMMANDS
  call       attached terminal process
  agent      attached terminal process with agent message formatting
  server     background process with a log; -w records its exit code
  detach     detached terminal process
  shell      attached shell; see backmux help shell

Put launch options before PROGRAM; subsequent arguments go to the program.
After call, agent, server, or detach, the next non-option argument is always
the program. These commands select the launch mode and reject -d/-i/-t;
-w is accepted only by server.

In the bare form, -- forces a program launch even if its name matches a
Backmux command or process. Shell expressions require a shell: sh -c '...'.
A lone TARGET reconnects to a running process, or restarts an ended one
using its recorded settings. A running process without an input console is
followed through its log.

MODE FLAGS
Without mode flags, launch an attached terminal process on a pseudoterminal
(PTY). In a script, its output streams with terminal line endings and merged
stdout/stderr. Use -i without -t for pipe input.

  -d, --detach       return immediately; print the Backmux process ID
  -w, --wait         retain exit tracking; with -d, launch still returns now
  -t, --tty          give the program a pseudoterminal
  -i, --interactive  keep input open; without -t, use a pipe

  -it    attached terminal process (call)
  -dt    detached terminal process (detach)
  -d     background process without recorded exit status (plain server)
  -dw    background process with recorded exit status (server -w)
  -di    detached pipe-input process; attach can supply input later

Terminal and pipe-input processes support peek, send, and msg, and record
exit codes. Pipe-input mode requires no active restart policy; it provides
a screen model without a terminal.
--rm and active restart policies also retain exit tracking. Plain -d without
those options leaves no Backmux helper.

PROGRAM SETTINGS
  --name NAME      assign a name; otherwise generate one. Names remain
                   reserved until record removal. Naming does not save a
                   profile; save and rename do.
  --size COLS ROWS set dimensions, each 1-1000; COLSxROWS also works.
                   Precedence: --size, saved detach-size for detached
                   terminals, invoking terminal size, then 80 24.
  -e, --env KEY=VALUE
                   set an environment variable; repeat for more variables
  --env-file FILE  read KEY=VALUE entries from a file
  --rm             remove the record, log, and saved screens after exit
  --restart POLICY
                   no (default), always, unless-stopped, or on-failure[:N].
                   Active policies require a non-terminal process.
  --restart-delay SECONDS
                   set a fixed delay for an active restart policy; 0 means
                   no delay. Default: 1 s, doubling to 30 s; reset after
                   a run lasting at least 10 s.

ATTACHMENT AND LOGS
  Ctrl-Space q     detach the active pane; its process keeps running
  Ctrl-Space ?     show keyboard shortcuts; see backmux help panes
  Ctrl-C           send interrupt input to the attached program
  Ctrl-D           with pipe input, submit buffered input or signal EOF
  --detach-keys KEYS
                   set the detach sequence (default: ctrl-space,q).
                   With two keys, the first is also the pane/chat prefix.
                   A single key, such as ctrl-], detaches immediately.
                   Other sequence lengths provide detach only.
  -f, --tail NAME  follow new log output without restarting the process;
                   Ctrl-C stops following and leaves the process running

COMMON OPTIONS
  --quiet          suppress normal status notes on stderr
  --system         request the root-managed store; see help system for routing
  -h, --help       show help (also backmux COMMAND --help)
  -V, --version    print the version

Launch value options accept --flag=value. Terminal processes default to
TERM=xterm-256color; -e TERM=... overrides it. Saved detach-size applies only
to new detached terminal processes; see backmux help config.

COMPATIBILITY
  --console        start a detached terminal process (equivalent to -dt).
                   The console command is a separate alias for attach.

Backmux launches host programs with the invoker's privileges. It does not
provide container images, port publishing, volume mounts, or capability
management. Programs normally start in the current working directory;
launches under sudo start in /. Use a shell or program option to change
directories when needed.

See backmux help targets, system, scripting, and aliases.
