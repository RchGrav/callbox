callbox help all - complete command and option reference

This reference includes launch options, target resolution, store selection,
scripting conventions, and every command's full help. Command and help-topic
aliases are listed at the end. Each section is also available on its own.

  callbox help COMMAND              one command (or callbox COMMAND --help)
  callbox help launch               start, detach, and restart programs
  callbox help targets              names, IDs, prefixes, and lookup order
  callbox help system               user and root-managed stores
  callbox help scripting            output conventions and exit codes

For complete workflows: callbox help tui, share, agents, messaging, service.
