backmux help all - complete command and option reference

This reference includes launch options, target resolution, store selection,
scripting conventions, and every command's help. Command and help-topic
aliases are listed at the end. Sections are also available individually.

  backmux help COMMAND              command syntax, options, and behavior
  backmux COMMAND --help            the same command reference
  backmux help launch               launch modes, options, and restart policies
  backmux help targets              names, IDs, prefixes, and lookup order
  backmux help system               user and root-managed stores
  backmux help scripting            output conventions and exit codes
