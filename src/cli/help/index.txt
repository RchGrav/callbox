backmux help all - everything backmux does

COMMANDS  backmux help <command>

LAUNCH                                    WATCH
  shell    Start your shell, panes, chat    list     List processes
  call     Start a program, attached        ps       Docker-style process list
  detach   Start a program, detached        info     Show a process's details
  server   Start a program, no terminal     inspect  Print a record as JSON
                                            logs     Print a process's output
DRIVE                                       tail     Follow new output
  attach   Attach to a running process      stats    Show CPU and memory use
  peek     Read a process's screen          ports    Show listening ports
  send     Send text, keys, mouse input
  wait     Wait for text, quiet, or exit  STOP AND REMOVE
  resize   Change a terminal's size         end      End: SIGTERM, then SIGKILL
                                            kill     End now: SIGKILL
MESSAGE                                     purge    Remove ended records
  msg      Message a process or person      delete   Remove a record, even saved
  inbox    Read replies sent to you
  monitor  Follow replies as they come    PROFILES AND SETTINGS
                                            recall   Restart an ended process
PANES                                       save     Keep a record (a profile)
  swap     Exchange two panes' places       rename   Rename and save a process
  layout   Save and load pane layouts       set      Change a profile setting
                                            unset    Clear a profile setting
HELP                                        config   Change your defaults
  help     Show help on a topic
  manual   Print the whole manual

  scripting  Output, timeouts, exit codes

  features   A closer look at what backmux does
