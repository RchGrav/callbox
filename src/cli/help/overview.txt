
Run terminal apps, inspect and control their screens, and connect agents.
A call gives a program a name and a captured log. It can keep running when
you detach; use its name to inspect it, reconnect, or stop it.

START A CALL
  callbox PROGRAM [ARGS...]         attached terminal, with a chat window
  callbox -it --name NAME PROGRAM   attached agent; messages go to its input
  callbox -dt --name NAME PROGRAM   detached terminal for peek and send
  callbox -dw --name NAME PROGRAM   background job; keep its exit code

WORK WITH CALLS (callbox COMMAND)
  ps                               list running calls (list: ended ones too)
  peek CALL                        read the screen; --image FILE saves a PNG
  send CALL TEXT --enter            type text and press Enter
  wait CALL --match TEXT            wait for screen text; no flags: for exit
  attach CALL                      reconnect; Ctrl-P Ctrl-Q detaches
  msg NAME TEXT                    send a message with a reply address
  inbox --wait                     read the next unread inbox message
  monitor                          follow that inbox until stopped
  logs CALL [-f]                    read captured output; -f follows it
  end CALL                         stop a call; purge CALL removes its record

  CALL is a name or ID; unique prefixes work.

FOLLOW A WORKFLOW
  callbox help tui                  troubleshoot a terminal app
  callbox help share                fix a TUI while a person watches and tests
  callbox help agents               start an agent and give it work
  callbox help messaging            exchange messages from any harness
  callbox help service              run background services and CI jobs

LOOK UP DETAILS
  callbox help COMMAND              syntax and options for one command
  callbox help launch               launch modes, flags, and restarting calls
  callbox help all                  complete command and option reference
