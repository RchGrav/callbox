
LAUNCH PROGRAMS
  backmux call PROGRAM [ARGS...]       start an attached terminal process
  backmux agent PROGRAM [ARGS...]      start with agent message formatting
  backmux server PROGRAM [ARGS...]     start a background process with a log
  backmux detach PROGRAM [ARGS...]     start a detached terminal process
  backmux shell [SHELL [ARGS...]]       start an attached shell
  Add --name NAME before PROGRAM to choose a process name.

MANAGE PROCESSES
  backmux list [all]                   list active processes; all adds records
  backmux attach TARGET               attach to a running process's console
  backmux tail TARGET                 follow new output from a running process
  backmux end TARGET...                send SIGTERM, then SIGKILL if needed
  backmux kill TARGET...               send SIGKILL immediately
  backmux recall TARGET                restart using recorded launch settings
  backmux info TARGET                  show process details and settings
  backmux purge                        remove ended, unsaved process records
  backmux purge all                    stop and remove all unsaved processes

MANAGE PROFILES
  backmux save TARGET                  protect a process record from purge
  backmux delete TARGET                remove an ended process, including saved
  backmux set TARGET SETTING[=VALUE]    change a process setting
  backmux unset TARGET SETTING         clear an optional process setting

TERMINAL CONTROLS
  Ctrl-Space q                         detach the active pane; keep it running
  Ctrl-Space c                         open or hide the chat window
  Ctrl-Space ?                         show keyboard shortcuts
  backmux help panes                   pane navigation, windows, layout, chat

HELP AND REFERENCE

  backmux help help                    index of workflow and reference topics
  backmux help aliases                 Docker-style command and option mappings
  backmux help all                     complete command and option reference
  backmux manual                       reference and worked examples
