
Run terminal apps, inspect and control their screens, and connect agents.
A call gives a program a name and a captured log. It can keep running when
you detach; use its name to inspect it, reconnect, or stop it.

START A CALL
  backmux PROGRAM [ARGS...]         attached terminal, with a chat window
  backmux -it --name NAME PROGRAM   attached agent; messages go to its input
  backmux -dt --name NAME PROGRAM   detached terminal for peek and send
  backmux -dw --name NAME PROGRAM   background job; keep its exit code

WORK WITH CALLS (backmux COMMAND)
  ps                               list running calls (list: ended ones too)
  peek CALL                        read the screen; --image FILE saves a PNG
  send CALL TEXT --enter            type text and press Enter
  wait CALL --match TEXT            wait for screen text; no flags: for exit
  attach CALL                      reconnect; Ctrl-P Ctrl-Q detaches
  msg NAME TEXT                    send a message with a reply address
  inbox --wait                     read the next unread inbox message
  monitor                          follow that inbox until stopped
  logs CALL [-f]                    read captured output; -f follows it
  end CALL                         stop a call; purge CALL removes its record

  CALL is a name or ID; unique prefixes work.

FOLLOW A WORKFLOW
  backmux help tui                  troubleshoot a terminal app
  backmux help share                fix a TUI while a person watches and tests
  backmux help agents               start an agent and give it work
  backmux help messaging            exchange messages from any harness
  backmux help service              run background services and CI jobs

LOOK UP DETAILS
  backmux help COMMAND              syntax and options for one command
  backmux help launch               launch modes, flags, and restarting calls
  backmux help all                  complete command and option reference
