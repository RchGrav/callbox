usage: backmux help [TOPIC]

Show help without starting or changing a process. With no topic, show the
overview. backmux -h and backmux --help show the same overview.

INTERACTIVE USE
  panes            pane navigation, windows, layout, profiles, and chat
  share            collaborate with an agent on a terminal application

AUTOMATION AND MESSAGING
  tui              inspect and control a terminal application
  agents           launch agents, assign work, and inspect progress
  messaging        send messages and receive replies through inboxes
  service          run background services and capture job results

REFERENCE
  COMMAND          command syntax, options, behavior, and related operations
  launch           launch modes and options
  targets          names, IDs, prefixes, and lookup order
  system           user and root-managed stores
  scripting        stdout, stderr, timeouts, and exit codes
  aliases          Docker-style command and option mappings
  all              complete command and option reference
  examples         application and automation examples
  features         capability overview

Topic aliases: users = share, comms = messaging, services = service,
run = launch. Command aliases share the canonical command's help.
