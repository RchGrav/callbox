usage: callbox list [-a|--all] [-s|--system] [-u|--user] [-l|--live] [name]

list is callbox's scoped ledger, with a USER column (CALL ID, USER, COMMAND,
CREATED, STATUS, PORTS, NAMES). By default you see your own calls, live and
past. Scope flags:

  -u/--user     your personal calls only (even under sudo: the invoking user's)
  -s/--system   the global (root-managed) calls only
  -a/--all      both scopes together
  -l/--live     narrow any of the above to running calls (composes)

Global calls a normal user is not entitled to read appear redacted: USER and
COMMAND read 'hidden'. Run as root, list defaults to the global calls; -a also
walks every user's store. An optional name narrows the listing. (For Docker's
running view, see ps.)
