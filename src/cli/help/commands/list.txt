usage: backmux list [all] [-s|--system] [-u|--user] [-a|--all] [name]

List active processes with owner, command, age, status, ports, and name.
Processes whose state is Unknown remain visible. all includes ended records.

  all              include ended and stale process records
  -l, --live       restrict the listing to active or Unknown processes
  -u, --user       select the invoking user's store, including under sudo
  -s, --system     select the root-managed store
  -a, --all        include both stores; distinct from the positional all

An optional name filters by exact process name across states, unless --live
is supplied. Normal users default to their own store. Root defaults to the
root-managed store; root's -a also scans user stores under the platform's
home directory root. Private root-managed processes show 'hidden' for owner
and command to other users.

For a combined user and root-managed view without an owner column, use ps.
