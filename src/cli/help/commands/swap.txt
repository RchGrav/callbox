usage: backmux swap <name|id>,<name|id>
       backmux swap <name|id> <name|id>

Exchange two panes' positions, identified by process name or Backmux process
ID. ID prefixes of at least four characters are accepted. This command does
not use the pane letters displayed by the interactive swap control.

From inside a pane, swap selects that pane's terminal. Otherwise, exactly one
terminal must be displaying panes; with several, run swap from the intended
terminal's pane. Example: backmux swap editor,reviewer

Interactive control: Ctrl-Space s. See backmux help panes for its keys.
