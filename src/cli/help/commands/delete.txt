usage: backmux delete <target>

Remove a record, even saved

Remove one process's record and its log, saved screens, message history and
console artifacts, saved or not. This releases its name.

delete never ends a process: one reported as running is refused, with the
command that ends it. A process found running on the next check (started
again in between) is ended before removal. An Unknown record can be removed;
removing it does not establish that the program has ended.

Use backmux end first to request shutdown.
