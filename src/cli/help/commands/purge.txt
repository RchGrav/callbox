usage: backmux purge [<target>|all] [-a|--all] [-s|--system] [-u|--user]
                     [--force]

Remove process records and their stored logs, screens, and message history.
Without a target, remove eligible ended records from the selected store.
With a target, remove that process's record.

  -a, --all        include stale records; does not change store selection
  -u, --user       select the invoking user's store (the default)
  -s, --system     select the root-managed store; invoke sudo if needed
  --force          with a target: allow removal when saved or running
                   without a target: include stale records, as -a does

TARGETED REMOVAL
With a target, --force stops a running process before removing its record.
An ordinary sweep preserves saved profiles and running processes, including
when --force is used without a target.

REMOVE ALL UNSAVED PROCESSES
purge all stops running, unsaved processes and removes unsaved records in
the selected store. It reports the number stopped and records removed.
Saved profiles are preserved.

--name assigns a name at launch; it does not save the profile. save and
rename mark profiles as saved. Removing a record releases its name.
Aliases: rm, prune, drop. Use end to stop a process without requesting removal.
