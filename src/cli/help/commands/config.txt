usage: backmux config get <setting>
       backmux config set <setting> <value>
       backmux config unset <setting>
settings: detach-size COLS ROWS, chat-name NAME

Read or change user defaults in ~/.config/backmux/config.

  detach-size COLS ROWS
    Default size for new detached terminal processes without --size.
    Precedence: --size, detach-size, invoking terminal size, then 80 24.
    Foreground launches ignore this setting. Existing processes retain
    their size; use backmux resize to change it.

  chat-name NAME
    Preferred name when creating your chat inbox, shared by your terminals.
    An existing inbox keeps its name. If the preference is unset or the name
    is unavailable, Backmux generates a name.

get prints the saved value and exits 1 if unset. set validates the value
before saving it. unset removes the saved value. A sudo launch reads the
invoking user's defaults; change those defaults without sudo.

Example: backmux config set detach-size 100 30
