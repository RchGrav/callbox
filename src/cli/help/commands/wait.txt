usage: backmux wait <target> [--idle [MS]] [--match TEXT | --regex RE]
                 [--since SEQ] [--exit] [--timeout MS]

Wait for screen content, output idle time, or process exit. With no condition,
wait for exit. For inbox messages, use inbox --wait or monitor.

SCREEN CONDITIONS
  --idle [MS]      wait for idle output (default: 500 ms). The process must
                   have produced output; without --since, the idle interval
                   starts no earlier than this wait. A process that has
                   never produced output does not meet this condition.
  --match TEXT     succeed when TEXT appears on screen; existing text counts
  --regex RE       match a POSIX extended regular expression on screen
  --since SEQ      require output after SEQ before testing screen conditions
                   on a running process; obtain SEQ with send --seq

PROCESS EXIT AND TIMEOUT
  --exit           succeed when the process ends. An exit-only wait prints
                   its recorded exit code; plain -d records none and prints
                   -1. Use -dw when the program's exit code is required.
  --timeout MS     limit the wait; 0 disables the timeout. Defaults: 30 s for
                   screen conditions, no timeout for an exit-only wait.

When conditions are combined, any one can complete the wait. Screen
conditions require a terminal or pipe-input console. A text match can also
succeed against an ended process's saved final screen. Output idle time
does not indicate task completion.

Durations accept milliseconds or ms, s, m suffixes, up to 24 hours.
Example: require output after input, then 300 ms of idle output:

  seq=$(backmux send app -k Down --seq)
  backmux wait app --since "$seq" --idle 300

For --rm processes, exit waits allow time for record removal. An exit note
keeps the recorded code available to wait for one minute after removal.

Exit status: 0 condition met, 7 timeout, 8 process ended before the condition.
A successful exit wait returns 0 even if the program failed. Its printed
exit code is separate; capture that value to propagate a job's result:

  code=$(backmux wait job)
  exit "$code"
