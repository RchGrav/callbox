usage: callbox msg <target> TEXT... [--stdin] [--no-enter] [-- TEXT...]
                   [--wait-reply [--timeout MS]]
       callbox msg [<target>] --received [ID]

Send text with a sender name and reply command. Input-enabled calls receive
it in their prompt, followed by Enter; calls with a chat window receive it
there instead. An outside sender's inbox receives stored text. Callbox
delivers immediately; input queueing is up to the receiving harness.

  [msg from NAME; reply: callbox msg NAME "..."] TEXT

Inside a call, CALLBOX_ID (or CALLBOX_NAME) identifies the sender. Outside
Callbox, the first send creates an inbox and prints its name on stderr.
The receiver replies with the same msg command in either case.

  --stdin          read the message text from stdin
  --no-enter       type without pressing Enter (for a call's program input)
  --               treat remaining words as text, including words with dashes
  --wait-reply     from outside Callbox, wait for the first new inbox message
                   after sending and print it; any sender can satisfy this
  --timeout MS     bound --wait-reply in milliseconds (0 = no limit, default)
  --received [ID]  read a call's delivered-message history, or one message by
                   its delivery ID. Name the call, or omit the target when
                   running inside the receiving call.
  -h, --help       show this page

TEXT arguments are joined with spaces. Multi-line text is pasted as one
bracketed paste when the receiving program enables it; otherwise line breaks
become spaces. Control characters and terminal escape sequences are removed.

Sending to a call prints its message ID on stdout. Sending to an outside
inbox succeeds without printing an ID. --wait-reply then prints the first
new message; it does not correlate a reply with a request or sender.
Delivery is not task completion. Plain -d and -dw calls have no input
console and refuse messages (exit 10). --received reads call history,
not outside inboxes; use inbox for those.

A call accepts at most 20 messages per minute. This limit does not apply to
outside inboxes. The header supplies an address, not proof of identity.
--wait-reply exits 7 on timeout or 8 if the inbox expires while waiting.

See callbox help messaging for inside and outside workflows.
