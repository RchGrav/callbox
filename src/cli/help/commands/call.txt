usage: backmux call [--name NAME] [options] <program> [<args>...]

Run a terminal program attached, on a PTY, under a name. Ctrl-Space q
detaches; it keeps running, and backmux attach NAME picks it back up.

Messages to it (backmux msg NAME TEXT, or chat) arrive raw: exactly the text,
then Enter, as if typed - so a message can run a command in a shell or a CLI.
backmux agent starts the same thing with messages formatted for an agent;
backmux set NAME agent switches a running process over.

Options: --name, -e KEY=VALUE, --env-file, --size COLS ROWS, --rm, --restart,
--detach-keys. The word after the options is always the program. Docker's
spelling: backmux run -it.
