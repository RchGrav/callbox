[person]
usage: backmux call [--name <name>] [options] <program> [<args>...]

Start a program, attached

Start an attached terminal process on a pseudoterminal (PTY). Ctrl-Space q
detaches the active pane and leaves its process running. Use backmux attach
NAME to reconnect.

Messages arrive as program input behind a header naming the sender and how
to reply, followed by Enter by default. To type text into the program as it
is, use backmux send. See backmux help msg for text handling and delivery.

Options include --name, -e <key>=<value>, --env-file, --size <cols> <rows>,
--rm, and --detach-keys. Options precede <program>; later arguments go to
the program.
Equivalent launch: backmux run -it. See backmux help launch and help panes.
