usage: backmux server [--name NAME] [-w] [options] <program> [<args>...]

Start a background process with output captured in a log and no terminal or
input console. Use tail to follow new output, or logs to read captured output.
Server processes cannot be attached as panes or receive input with send/msg.

  -w    retain a waiter to record the program's exit code for backmux wait

A plain server launch without -w, --rm, or an active restart policy leaves
no Backmux helper and does not record an exit code. --rm and active restart
policies also retain exit tracking.

Options include --name, -e KEY=VALUE, --env-file, --rm, and --restart.
Equivalent launch: backmux run -d. See backmux help launch and help service.
