[person]
usage: backmux attach <target> [--detach-keys <keys>]

Attach to a running process

Connect this terminal to a running process's console. Terminal processes
and pipe-input processes (-i without -t) support attach. console is an alias.

TERMINAL PROCESS CONTROLS
  Ctrl-Space q     detach the active pane; its process keeps running
  Ctrl-Space ?     show keyboard shortcuts
  Ctrl-Space p a   select another terminal process to attach as a pane

Ctrl-Space is a prefix: press and release it, then press the next key.
The prefix has no timeout. Press it twice to send one Ctrl-Space to the
program. An unrecognized prefix command is discarded.

--detach-keys <keys> changes the detach sequence for this attach. For example,
--detach-keys ctrl-a,ctrl-d uses Ctrl-A as the prefix and Ctrl-D to detach.
Two-key sequences retain pane and chat controls under the new prefix.
A one-key sequence such as ctrl-] detaches immediately; sequences of other
lengths do not provide pane or chat controls.

Each process has one active attachment. A new attach replaces the previous
client without stopping the process. A disconnected client releases the console.
For nested attachments, the detach sequence acts on the innermost attachment
first; repeating it detaches the enclosing attachment.

PIPE INPUT
Without an interactive terminal, attach forwards stdin and follows output
until the process ends. End of stdin does not close the process's input;
a later attach can send more input. For scripted control, see backmux help
send, peek, and wait. For interactive controls, see backmux help panes.
