usage: backmux send <target> [<text>]... [--text <text>] [-k <key>]...
                 [--keys "K1 K2"] [--enter] [--paste <text>|-] [--stdin] [--seq]
                 [--mouse <action>,<col>,<row>[,<button>]]
                 [--wait <ms> [--timeout <ms>]]

Send text, keys, mouse input

Send input without attaching. Terminal processes and pipe-input processes
(-i without -t) accept input; server processes do not.
Input operations are applied in argument order.

TEXT AND KEYS
  <text>           send literal text; adjacent arguments add no spaces
  --text <text>    send literal text, including text starting with a dash
  --               treat all remaining arguments as literal text
  -k, --key <key>  send Enter, Tab, Escape, Backspace, Space, Up, Down, Left,
                   Right, Home, End, PageUp, PageDown, Insert, Delete,
                   or F1-F24; modifiers: C- (Ctrl), M- (Alt), S- (Shift)
  --keys "<k1> <k2>"
                   send several keys, for example --keys "C-a C-k"
  --enter          send Enter
  --paste <text>   paste text; use bracketed paste when enabled by the program
                   (--paste - reads stdin)
  --stdin          send stdin as literal input

MOUSE
  --mouse <action>,<col>,<row>[,<button>]
                   send click, press, release, move, drag, scroll-up, or
                   scroll-down. <col>,<row> are zero-based. BUTTON: 1 left
                   (default), 2 middle, 3 right. Drag: press, drag, release.
                   Exit 9 means mouse reporting is disabled and the mouse
                   event was not delivered.

OUTPUT WAIT
  --wait <ms>      after sending, require new output followed by MS of idle
                   output; --timeout bounds this wait (default: 10 s)
  --seq            print the output counter captured before input delivery,
                   for use with backmux wait --since

Key encoding follows the program's current terminal modes. Some programs
interpret Escape followed immediately by another key as an Alt combination;
send Escape in a separate invocation when that distinction matters.

--wait can time out after successful delivery if no output follows the input.
Durations accept milliseconds or ms, s, m suffixes, such as 1.5s, up to
24 hours. --timeout 0 disables the timeout. See backmux help wait.
