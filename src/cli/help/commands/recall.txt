usage: backmux recall <target>

Restart an ended process

Relaunch the recorded command with its stored arguments, working directory,
and launch mode. The process retains its name and Backmux process ID.
Existing log output is retained.

A shell comes back as it was last observed (list, info and save observe
it): in the directory it was in, then with its environment source (set NAME
source=FILE) and the program it was running, with the same arguments, in
that program's own directory; the shell stays after it ends. A pipeline is
not started again (one command line cannot rebuild it), and recall says so.
Arguments are passed exactly as typed, so a program launched directly comes
back where it was launched.

Targets reported as running are refused. Unknown targets can proceed to
relaunch; that state does not confirm that the previous execution ended.

Use set to change program, args, or working before the next launch. Unsetting
working makes recall use its caller's working directory.

Use attach or tail to access a process that is already running.
start is an alias. See backmux help set and help launch.
