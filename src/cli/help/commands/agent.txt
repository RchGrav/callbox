usage: backmux agent [--name NAME] [options] <program> [<args>...]

Start an attached terminal process with the agent setting enabled. Messages
include the sender's name and a reply command before the message text:

  [msg from NAME; reply: backmux msg NAME "..."] TEXT

The agent setting controls message formatting. Change it on a running or
ended process with backmux set NAME agent or backmux unset NAME agent.
The change applies to the next message without restarting the process.

Launch options are the same as for call. See backmux help launch for options
and backmux help agents for a delegation workflow.
