usage: backmux agent [--name NAME] [options] <program> [<args>...]

backmux call, with messages formatted for an agent: each one arrives with a
header naming the sender and how to reply,

  [msg from NAME; reply: backmux msg NAME "..."] the text

so the agent knows who wrote and can answer. agent is a setting, not a kind
of process: backmux set NAME agent / backmux unset NAME agent turn it on and off
from the next message, with no relaunch.

Options: as for backmux call. backmux help agents shows the whole loop.
