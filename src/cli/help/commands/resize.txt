usage: backmux resize <target> <cols> <rows>   (or <cols>x<rows>)

Set a running terminal process's dimensions. Columns and rows must each be
1-1000. The terminal size and screen model are updated, and the terminal's
foreground process group receives SIGWINCH when its dimensions change.

For a pipe-input process (-i without -t), only the screen model changes;
there is no terminal to resize or terminal foreground group to signal.

Example: backmux resize app 100 30
Use --size at launch or config set detach-size for new detached terminals.
