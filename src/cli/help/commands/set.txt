usage: backmux set <name|id> <setting>[=<value>]
       backmux unset <name|id> <setting>

Change settings on a running or ended process.

  working=DIR        working directory for the next launch; unset uses
                     the directory from which recall is invoked
  program=PROGRAM    executable path or name on PATH for the next launch;
                     cannot be unset
  args=TEXT          replace arguments, splitting TEXT at spaces and tabs;
                     quote the assignment when it contains spaces
  args -- ARG...     replace arguments with the shell's argument list,
                     preserving quoted spaces; unset args clears them
  name=NAME          rename and save the profile immediately; cannot be unset

working, program, and args affect the next launch through recall. They do
not change the running program. The Backmux process ID remains unchanged.

Examples:
  backmux set worker working=/srv/project
  backmux set worker 'args=--port 8080'
  backmux set worker args -- --title "Build results"
  backmux unset worker working

See backmux help rename and help recall.
