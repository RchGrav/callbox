usage: backmux unset <name|id> <setting>

Clear an optional setting on a running or ended process.

  agent      disable the sender header for subsequent messages
  working    use the caller's working directory on the next recall
  args       remove all recorded arguments for the next recall

program and name are required and cannot be unset. Use set to replace them.
Changes to working and args do not affect the running program.

Example: backmux unset worker args
See backmux help set for all settings and argument syntax.
