backmux help share - fix a TUI while a person watches and tests

Use this when you want your coding agent to reproduce and fix an issue
without losing sight of the app. You stay attached; the agent inspects and
drives the same screen. Take turns providing input to avoid overlapping keys.

OPEN YOUR AGENT AND APP
  This example assumes Codex is installed and configured, and ./my-tui is
  your built application. Use your own terminal agent and app as needed.

    backmux detach --name coder codex
    backmux set coder agent
    backmux peek coder
    backmux call --name app ./my-tui

  Check that coder is ready for a prompt before starting the app. The app
  runs on your terminal. Press Ctrl-Space p a and choose coder: it joins as a
  pane beside the app, so you watch both. Click a pane to type in it.

DESCRIBE AND REPRODUCE THE ISSUE
  Press Ctrl-Space c to open your chat, then Tab to choose coder. For
  example:

    In process app, Down skips a menu item. Reproduce it with peek and send,
    fix the navigation code, and tell me when to restart and test it.

  Enter sends it; Esc hides chat. It reaches coder with your chat name and
  the reply command, so coder answers with backmux msg <your name>, and the
  answer lands in your chat. The agent can now use its command tool while
  you watch:

    backmux peek app --image bug.png --cursor-ring
    backmux send app -k Down --wait 300
    backmux peek app --json

  (A message to app itself would be typed into the app: app is a process, not
  an agent. Agents talk to you, by your chat name.)

REBUILD AND TEST TOGETHER
  Quit the app normally so the agent can rebuild it; its pane closes and
  coder fills the screen. Once coder's report confirms the new build is
  ready, start the app again from a shell:

    backmux recall app

  recall reuses the recorded command, arguments and folder, so the rebuilt
  executable opens attached again. Test the fix and tell coder in chat.

  When finished, quit the app and release both names:

    backmux end coder
    backmux purge app
    backmux purge coder

JOIN AN APP YOUR AGENT ALREADY STARTED
  If the agent launched the app with backmux detach, use this instead:

    backmux attach app

  Ctrl-Space q detaches and leaves it running. Only one interactive attach
  is allowed at a time; peek, send, and resize still work while you are
  attached.
