backmux help share - fix a TUI while a person watches and tests

Use this when you want your coding agent to reproduce and fix an issue
without losing sight of the app. You stay attached; the agent inspects and
drives the same screen. Take turns providing input to avoid overlapping keys.

OPEN YOUR AGENT AND APP
  This example assumes Codex is installed and configured, and ./my-tui is
  your built application. Use your own terminal agent and app as needed.

    backmux -dt --name coder codex
    backmux peek coder
    backmux --name app -- ./my-tui

  Check that coder is ready for a prompt before starting the app. The bare
  app launch keeps it on your terminal and adds a separate chat window.
  Messages to app appear in chat; they are not typed into the application.

DESCRIBE AND REPRODUCE THE ISSUE
  Press Ctrl-P Ctrl-T to open chat, then Tab to choose coder. For example:

    In call app, Down skips a menu item. Reproduce it with peek and send,
    fix the navigation code, and tell me when to restart and test it.

  Ctrl-S adds a snapshot of the app's screen to the message. Enter sends
  it; Esc hides chat. The agent can now use its command tool while you watch:

    backmux peek app --image bug.png --cursor-ring
    backmux send app -k Down --wait 300
    backmux peek app --json
    backmux msg app "I reproduced it; please quit the app for the rebuild."

REBUILD AND TEST TOGETHER
  Quit the app normally so the agent can rebuild it. The app's chat is
  unavailable while it is stopped; check the agent's own screen instead:

    backmux peek coder

  You can attach to coder to talk directly; Ctrl-P Ctrl-Q detaches again.
  Once its report confirms the new build is ready, run this in your terminal:

    backmux app

  An ended call reuses its recorded command and launch mode, so the rebuilt
  executable opens attached with chat again. Test the reported fix and send
  your result to coder. This restarts the app; it does not rebuild it.

  When finished, quit the app and release both names:

    backmux end coder
    backmux purge app
    backmux purge coder

JOIN AN APP YOUR AGENT ALREADY STARTED
  If the agent launched a detached terminal with -dt, use this instead:

    backmux attach app

  Ctrl-P Ctrl-Q detaches and leaves it running. A -dt call keeps its
  original message mode, so attaching does not add a chat window. Use your
  existing conversation with the agent. Only one interactive attach is
  allowed at a time; peek, send, and resize still work while you are attached.
