backmux help tui - troubleshoot a terminal app

Use this when your command tool can launch a full-screen app but cannot
operate its terminal. Give the app a detached terminal, look at its screen,
send input, and check the result. You can inspect colors and the cursor as
well as text; a person can attach to the same process to try it themselves.

START AND INSPECT
  This example requires a Vim-compatible vi. It opens an empty buffer with
  personal settings and history disabled, and mouse reporting enabled.

    backmux -dt --name editor --size 80 24 -- \
      vi -u NONE -N -i NONE -c 'set mouse=a ttymouse=sgr'
    backmux wait editor --idle 300
    backmux peek editor --ruler
    backmux peek editor --image before.png --cursor-ring

  -dt starts a terminal without attaching you to it. --size makes the
  starting layout repeatable. peek reads the visible screen; --ruler adds
  zero-based coordinates, and --image writes a color PNG.

ACT AND VERIFY
    backmux send editor i 'Backmux test' -k Escape --wait 300
    backmux wait editor --match 'Backmux test'
    backmux send editor --mouse click,4,0
    backmux peek editor --json
    backmux resize editor 100 30
    backmux wait editor --idle 300
    backmux peek editor --image after.png --cursor-ring

  send applies text and keys in order. Mouse coordinates are column,row;
  the app must enable mouse reporting (otherwise send exits 9). --json
  reports the cursor position, input modes, size, and output counter.
  resize changes the terminal dimensions and notifies the app with SIGWINCH.

  --wait 300 waits for output after the input, followed by 300 ms of quiet.
  Quiet means ready to inspect, not correct: verify the text, cursor, or
  image you expected. An input that draws nothing can time out even if it
  was delivered. Screen waits default to 30 s; send --wait defaults to 10 s.

FINISH OR HAND OVER
    backmux send editor ':q!' --enter
    backmux wait editor
    backmux peek editor --last-alt
    backmux purge editor

  wait without a condition waits for exit and prints the program's code.
  --last-alt shows the saved full-screen frame after an app switches back.
  purge removes the ended process and frees its name.

  For your app, replace vi and its inputs with your reproduction steps.
  If it already runs in Backmux, use its name. A person can join a running
  terminal with backmux attach NAME; Ctrl-Space q leaves it running.
  Backmux cannot adopt a process that was started outside it.

WHEN A SCREEN IS MISLEADING
  To require a redraw after an input, capture its output counter:

    seq=$(backmux send app -k Down --seq)
    backmux wait app --since "$seq" --idle 300

  Use backmux logs app | cat -v to inspect the raw output. Some apps read
  Escape followed quickly by another key as Alt: send Escape separately.
