backmux help aliases - Docker-style commands and options

Backmux accepts selected Docker-style command forms for host processes.
It does not provide containers, images, volume mounts, or port publishing.

  Accepted form     Native Backmux command
  run -it           call
  run -d            server
  run -dw           server -w (Backmux extension: record the exit code)
  run -dt           detach
  start             recall
  stop              end
  kill              kill
  ps                ps (active processes)
  ps -a             ps -a (include ended process records)
  logs [-f]         logs [-f]
  attach            attach
  inspect           inspect (JSON); info provides a text summary
  rm [-f]           rm (remove the named processes)
  rename            rename TARGET NAME (also saves the profile)

list provides store selection and an owner column; list all includes ended
records. ps combines user and root-managed records for normal users; root's
ps reads the root-managed store. See backmux help list and help ps.

Supported launch options include --name, -e, --env-file, --rm, --restart,
and --detach-keys. Container-specific options such as -p, -v, --privileged,
and --cap-add are rejected.

exec has no equivalent. Start another host process with backmux call PROGRAM.
