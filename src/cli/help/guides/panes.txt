backmux help panes - terminal controls, panes, windows, and chat

A pane displays one attached terminal process. A numbered window holds up to
four panes, with the first split arranged left/right. There are nine windows.
Pane controls require an interactive terminal and a two-key detach sequence.
From a single-process attach, press Ctrl-Space o to open the process
launcher and attach another terminal process. The controls below apply
while the pane interface is active. backmux shell starts with it: a cleared
screen, chat open, the bar along the bottom.

PREFIX AND HELP
The default prefix is Ctrl-Space: press and release it, then press a command
key. It has no timeout. Press Ctrl-Space twice to send one Ctrl-Space to the
program. Unrecognized prefix commands are discarded. A custom two-key
--detach-keys sequence changes the prefix and detach key; help shows those
configured keys.

  Ctrl-Space ?     show keyboard shortcuts
  Ctrl-Space o     open the process launcher
  Ctrl-Space p     enter Pane Navigation mode
  Ctrl-Space t     enter Window Navigation mode
  Ctrl-Space r     enter Pane Resizing mode
  Ctrl-Space m     enter Pane Placement mode

In a mode, press ? for contextual help. Esc or Enter exits the mode.
Esc closes contextual help first; press Esc again to exit the mode.

PANE NAVIGATION
  Alt-arrows       focus an adjacent pane, unless the active pane is locked
  Click a pane     focus that pane

In Pane Navigation mode:
  arrows, h j k l   focus an adjacent pane (h left, j down, k up, l right)
  a                open the launcher on its running terminals
  g                select an attached pane by name
  z                toggle the active pane's full-screen view

THE LAUNCHER
Ctrl-Space o, or a counter on the bar. Tab or Left/Right steps through its
lists, Up/Down selects, Enter acts, Esc cancels:
  Terminals        running terminal processes: attach one as a pane
  Consoles         pipe-input processes and servers: open one in a viewer
                   pane (NAME-view runs backmux attach, NAME-log backmux
                   logs -f; either leaves no record once closed)
  Ended            ended processes: start one again; a terminal becomes a
                   pane (a shell comes back with backmux NAME)

WINDOW NAVIGATION
In Window Navigation mode:
  1-9              select an occupied window and exit the mode
  Left/Right, h l  select the previous or next occupied window

PANE RESIZING
In Pane Resizing mode:
  arrows, h j k l        expand toward an adjacent pane
  Shift-arrows, H J K L  shrink at the selected shared divider
  =                     equalize the current window's dividers

Only shared dividers can move. Resizing changes the attached programs'
terminal dimensions. Full-screen view does not resize dividers.

PANE PLACEMENT AND LAYOUT
In Pane Placement mode:
  arrows, h j k l   swap with an adjacent pane
  1-9              move the active pane to that window and exit the mode

Additional prefix commands:
  Ctrl-Space s     select panes to swap by their displayed letters; select
                   a letter then 1-9 to move that pane to a window
  Ctrl-Space w     distribute panes across windows
  Ctrl-Space a     sort panes by process name in existing occupied positions
  Ctrl-Space d     pack panes into windows, up to four per window
  Ctrl-Space z     toggle the active pane's full-screen view
  Ctrl-Space f     hide or show the bar along the bottom
  Ctrl-Space i     hide or show the name bars (Info)

Moving a pane to another window leaves the current window selected when it
still contains panes. Layout changes preserve the running processes.
For scripted swaps by process name or ID, see backmux help swap.

NAME BARS AND THE BAR
With Info on, each pane's name bar shows its letter and state at the left,
its name boxed in the middle, and what it runs with its CPU and memory at
the right. Click the name box (or Ctrl-Space n) to type a new name over it:
Enter renames, Esc or a click elsewhere keeps the name.

The bar along the bottom, from the left: running terminals (green),
consoles that scroll (blue), ended processes (red) - click one for its list
in the launcher - then your chat name (opens or hides chat; red while
messages wait), Info, the windows (click one to go there), Zoom, Lock, ?,
and the machine's CPU and memory. Toggles look different on and off. On a
narrow terminal items shorten, then the least useful go.

PROFILES AND INPUT
  Ctrl-Space n     rename the active pane's process; also save its profile
  Ctrl-Space ;     save the active process profile, optionally under a new name
  Ctrl-Space \     toggle pane lock

A locked pane forwards Alt-arrows to its program instead of changing focus.
Prefix commands remain available. Saving preserves a process profile from
purge; it does not save the window layout.

CHAT
Chat lists agent harnesses only (claude, codex, gemini, ...; see backmux
help shell), each with its harness's name.
  Ctrl-Space c     open chat (on the active pane's agent, if it is one); hide
                   it when chat has keyboard focus, or return focus to it
  Esc             hide chat
  Tab             open the recipient picker; type to filter, Up/Down to
                   select, Enter to confirm
  Enter           send the message
  Ctrl-J          insert a newline
  Ctrl-S          Assist: ask the agent for help with the app on screen
  Up/Down         scroll conversation history; PageUp/PageDown scroll a page

Drag the chat title bar to move the window or its lower-right corner to
resize it. Click its close control to hide it. Click a pane to return
keyboard focus to that program.

DETACH
Ctrl-Space q detaches the active pane and leaves its process running. Other
panes remain attached. Detaching the final pane returns to the caller.
Use backmux attach NAME to reconnect; end and kill stop processes.

See backmux help attach, shell, msg, set, and config.
